# Capturas requeridas después del despliegue

Estas capturas deben obtenerse de la aplicación realmente desplegada, no de mockups.

1. **Aplicación funcional:** ventana completa con título, aviso de alcance, indicadores y visualización principal.
2. **Filtros funcionales:** barra lateral visible con varias entidades y un rango de fechas seleccionado.
3. **Evidencia de interacción:** dos capturas con filtros distintos donde cambien indicadores o gráficos.
4. **Dashboard integrado:** pestaña de consumo con línea, barras, promedio móvil y tabla.
5. **Red comercial:** pestaña abierta con el filtro de volumen y grafo visible.
6. **Repositorio vinculado:** página del repositorio GitHub mostrando `app.py`, `requirements.txt` y los CSV.
7. **Streamlit Cloud:** panel de despliegue que muestre repositorio, rama y archivo principal.
8. **Liga pública:** aplicación abierta en una ventana de incógnito para demostrar acceso sin iniciar sesión.

Recomendaciones: resolución de 1920×1080 si es posible, navegador al 100% de zoom, sin menús que tapen información, y nombres de archivo secuenciales `01_app.png` … `08_public_url.png`.

La liga pública y las capturas de Streamlit Cloud solo se pueden completar una vez que el usuario autorice GitHub y termine el despliegue en su cuenta.
